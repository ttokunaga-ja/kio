# F4 後の作業計画

[v1 の計画](v1-plan.md) §6 の「v1 後」と、F4 後に残った課題をここで管理する。作業が進んだら、表の「状態」と「チェックポイント」を書き換える。経過は commit に残し、ここには積まない。

- 状態：`完了`・`進行中`・`未着手`・`要判断`（利用者の決定待ち）・`保留`。
- 人日：人間の開発者 1 人が設計・実装・検証まで行う場合の概算。Codex に委譲すると実時間はこれより短いが、統合・検証・CI の待ち時間は短くならない。
- 暦日（並列）：独立した単位を並列に進めた場合の、クリティカルパスの日数。CI 1 回は約 1.5 時間で、0.25 日として数える。
